# 🌤️ SkyCast  – Live Weather Dashboard

A modern, responsive weather dashboard that helps users explore real-time weather information, forecasts, air quality, and interactive weather maps.

## ✨ Features

- 🌡️ Live weather information
- 🔍 City search and current location detection
- 🌡️ Celsius and Fahrenheit conversion
- 🕒 Hourly weather forecast
- 📅 7-day weather forecast
- 📊 Temperature charts
- 🌫️ Air Quality Index (AQI)
- 🌧️ Rain, Clouds and Temperature weather maps
- 🌅 Sunrise and Sunset countdown
- 🌂 Smart outfit and umbrella advisor
- ⚠️ Weather alerts and insights
- 🌍 Two-city weather comparison
- 📥 Downloadable weather card (PNG)
- 🕘 Search history
- 🎨 Dark and Light themes
- 📱 Responsive design
- 🌤️ Dynamic weather backgrounds

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Open-Meteo API
- Leaflet.js
- RainViewer Weather Radar
- OpenWeather Map Tiles
- Cloudflare Workers

## 🌐 APIs and Data Sources

- [Open-Meteo](https://open-meteo.com/)
- [RainViewer](https://www.rainviewer.com/)
- [OpenWeather](https://openweathermap.org/)
- [OpenStreetMap](https://www.openstreetmap.org/)

## 🚀 Getting Started

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Configure the required weather map API key through the Cloudflare Worker environment secret.
4. Open `index.html` using Live Server.
5. Search for a city and explore the weather dashboard.

## 🔐 Security

- OpenWeather API key is stored as a Cloudflare Worker secret.
- API credentials should never be committed to the public repository.
